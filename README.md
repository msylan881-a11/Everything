# NAQSH AI — Android MVP source

This package contains a Flutter Android app source, a FastAPI backend starter, a SQL schema draft, and a GitHub Actions workflow that can build a debug APK in the cloud.

**This is not a finished commercial app or a prebuilt APK.** The workflow produces a test APK only. Real AI image editing requires configuring a real provider on the backend; account security, payment/subscription validation, ads, production hosting, privacy policy, and device testing remain unfinished.

For cloud APK instructions, read `BUILD_APK_ONLINE.md`.
