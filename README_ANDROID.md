# إعداد Android
1. أنشئ ملفات المنصة عبر `flutter create mobile` قبل نسخ ملفات الحزمة.
2. للإنتاج استخدم HTTPS ولا تسمح باتصالات HTTP غير المشفرة.
3. اضبط `applicationId` فريدًا ونسخة التطبيق ومفتاح توقيع آمنًا.
4. اختبر اختيار الصور والكاميرا على جهاز حقيقي.
5. راجع سياسة الخصوصية وحذف الحساب والبيانات ومتطلبات Google Play.
